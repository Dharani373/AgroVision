# 🌱 AgroVision

AI-Powered Crop Management Platform

AgroVision is a full-stack Machine Learning + MERN application designed to help farmers make data-driven crop management decisions.

## Tech Stack

- React
- Node.js
- Express.js
- MongoDB
- Python
- FastAPI
- Scikit-learn
- XGBoost
- TensorFlow / PyTorch

## Project Structure

- `client` - React frontend
- `server` - Node.js + Express backend
- `ml` - Python + FastAPI ML service
- `docs` - Project documentation
